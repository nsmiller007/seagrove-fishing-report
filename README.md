# Seagrove Beach Fishing Report • 30A

A single-page, static fishing report/dashboard for Seagrove Beach and the 30A area (Walton County, Florida).

## Features
- Interactive Leaflet map of local fishing spots and bait/tackle shops (with addresses and phone numbers)
- Links to local surf reports, beach webcams (SoWal), tides, NWS forecast
- Links to FWC saltwater recreational fishing regulations (e.g. red drum)
- Dark, mobile-friendly layout

## Requirements
Just a modern web browser. Leaflet and Google Fonts load from CDNs, so an internet connection is needed.

## Run
Open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000/
```

It can also be hosted as-is on GitHub Pages.

## Disclaimer
Informational only. Always check current FWC regulations and conditions before fishing.
